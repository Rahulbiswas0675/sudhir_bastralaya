# Sudhir Bastralaya

Premium static fashion landing page for Sudhir Bastralaya (Karimpur, Nadia).

## Stack

- HTML5
- Tailwind CSS (compiled locally to `assets/css/tailwind.css`)
- Custom CSS
- Vanilla JavaScript (ES modules)

No backend. Ready for Hostinger, Netlify, GitHub Pages, or any static host.

## Local preview

```bash
python3 -m http.server 8765
```

Open `http://127.0.0.1:8765/`.

ES modules require HTTP (do not open `index.html` as a `file://` URL).

## Rebuild CSS after class changes

```bash
npm install
npm run build:css
```

Hosting does **not** require Node.js—commit and deploy the compiled CSS.
